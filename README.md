# "Big Data and Its Tools" Course Repository

This repository contains coursework and assignments for the class **Big Data and Its Tools**.

## Homework
There are 6 homework assignments included in this repository. They cover basic Java programming tasks related to big data processing, including simple exercises using **MapReduce**.
